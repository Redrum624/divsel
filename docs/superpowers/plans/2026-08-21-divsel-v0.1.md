## The algorithm, transcribed from the paper

Everything in this section is the contract. Implementations elsewhere (Aura, limbic) conform to *this*.

**Problem (MDMS).** Ground set `V`, `n = |V|`, in a **metric space** (triangle inequality is used in the proofs — Lemma C.1). `g : 2^V → ℝ≥0` monotone submodular. Marginal `g(v|S) = g(S ∪ {v}) − g(S)`.

```
div(S) = min_{u≠v ∈ S} dist(u,v)        if |S| ≥ 2
       = d_max = max_{u,v ∈ V} dist(u,v) if |S| ≤ 1     ← NOT 0. Makes div monotone decreasing.

dist(u, ∅) = ∞
f(S)  = g(S) + λ·div(S),  λ ≥ 0
maximize f(S) subject to |S| ≤ k        ← inequality, not equality
```

`f` is **not** submodular (Remark 2.1, Appendix A) and plain greedy on `f` has no constant-factor guarantee (Appendix B). That is the whole reason GIST exists.

**Algorithm 1 — GIST**

```
GIST(V, g, k, eps):
  1: S ← GreedyIndependentSet(V, g, 0, k)                 # classic greedy (d=0)
  2: d_max ← max_{u,v ∈ V} dist(u,v)                      # diameter
  3: T ← {u,v} achieving d_max
  4: if f(T) > f(S) and k ≥ 2:                            # strict >
  5:     S ← T
  6: D ← { (1+eps)^i · eps·d_max/2 : (1+eps)^i ≤ 2/eps, i ∈ ℤ≥0 }
  7: for d in D:
  8:     T ← GreedyIndependentSet(V, g, d, k)
  9:     if f(T) ≥ f(S):                                  # non-strict ≥
 10:         S ← T
 11: return S
```

`D` is a **geometric sequence with ratio (1+eps)** starting at `eps·d_max/2` — *not* quantiles, *not* a fixed absolute grid. `|D| = 1 + ⌊log_{1+eps}(2/eps)⌋`. Only `d_max` is needed to build it.

**GreedyIndependentSet — the bicriteria greedy**

```
GreedyIndependentSet(V, g, d, k):
  1: S ← {}
  2: for i in 1..k:
  3:     C ← { v ∈ V \ S : dist(v,S) ≥ d }
  4:     if C = {}: return S                              # S is maximal independent in G_d(V)
  5:     t ← argmax_{v ∈ C} g(v | S)                       # marginal gain of g ALONE
  6:     S ← S ∪ {t}
  7: return S
```

Selection maximizes the marginal gain of **`g` only** — `λ` and `div` never enter the selection rule. Diversity enters *solely* as the hard feasibility filter `dist(v,S) ≥ d`. With `d = 0` this is exactly classic Nemhauser greedy.

**Guarantees.** Theorem 3.1: `f(S) ≥ (1/2 − eps)·OPT` for monotone submodular `g`, using `O(n·k·log_{1+eps}(1/eps))` oracle queries. Theorem 3.3: `f(S) ≥ (2/3 − eps)·OPT` for **linear** `g(S)=Σw(v)`, `w ≥ 0` — and exactly `2/3` with the exhaustive threshold set `D = {dist(u,v)/2 : u,v ∈ V}`. Bicriteria (Lemma 3.2): running at `d' < d/2` yields `g(T) ≥ g(S*_d)/2`; for linear `g` (Lemma C.1) `d' ≤ d/2` yields `w(T) ≥ w(S*_d)` with **no** factor-2 loss. Hardness (Theorem 4.1): NP-hard beyond `2(1−1/e)/(2(1−1/e)+1) + δ < 0.55836`. Theorem 4.2: no `(2/3+eps)` for linear `g` unless P=NP — tight against 3.3.

**Not specified by the paper → `[divsel choice]`:** argmax tie-breaking in GreedyIndependentSet line 5. divsel breaks ties by **lowest index**, making every run deterministic. Documented in the README and asserted in tests.

**Files:** Create `crates/divsel/src/metric.rs`, `crates/divsel/src/points.rs` · Test: inline `#[cfg(test)]`

**Interfaces (produced):**

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Metric { Cosine, Euclidean }   // Cosine = 1 - dot(a,b) on L2-normalized rows

pub struct Points { data: Vec<f32>, n: usize, dim: usize, metric: Metric }
impl Points {
    pub fn new(data: Vec<f32>, dim: usize, metric: Metric) -> Result<Self, DivselError>;
    pub fn n(&self) -> usize;
    pub fn dim(&self) -> usize;
    pub fn dist(&self, i: usize, j: usize) -> f32;   // scalar reference impl (Task 6 adds SIMD)
    pub fn diameter(&self) -> (f32, usize, usize);   // (d_max, u, v) — exact O(n²), parallel
}
```

**Note on `Metric::Cosine`:** the paper's ImageNet experiment uses cosine distance `1 − eᵢ·eⱼ` on **unit-length** embeddings. `Points::new` L2-normalizes rows when `metric == Cosine` and records that it did. Cosine distance on unit vectors satisfies the triangle inequality only in its square-root (angular) form; divsel documents this honestly — the guarantee's metric precondition holds strictly for `Euclidean` and for angular distance, and is used as a well-behaved heuristic for raw cosine distance, which is what the paper's own experiments do.

### Task 2: Utility functions

**Files:** Create `crates/divsel/src/utility.rs` · Test: inline

**Interfaces (produced):**

```rust
/// Monotone submodular g. Implementations must be monotone and submodular;
/// divsel cannot verify this and says so in the docs.
pub trait Utility: Sync {
    /// g(v | S) — marginal gain of adding `v` to the current selection.
    fn marginal(&self, v: usize, selected: &[usize], pts: &Points) -> f64;
    /// Called after `v` is committed, so implementations can update caches.
    fn commit(&mut self, v: usize, pts: &Points);
    fn reset(&mut self);
    /// True when marginals never change (enables the CELF fast path).
    fn is_linear(&self) -> bool { false }
}

pub struct Linear { pub weights: Vec<f64> }            // is_linear() == true
pub struct Coverage { /* sparse sets per element */ }
pub struct FacilityLocation { /* max-similarity cache, len n */ }
```

`FacilityLocation` is the one `gist-select` lacks: `g(S) = Σ_{i∈V} max_{j∈S} sim(i,j)`, maintained with an `O(n)` running-max cache so `marginal` is `O(n)` and `commit` is `O(n)`.

- [ ] Steps: failing tests per utility (Linear marginals constant; Coverage marginal = newly-covered count; FacilityLocation submodularity spot-check `g(v|S) ≥ g(v|T)` for `S ⊂ T` on a random 30-point set) → implement → green → commit.

### Task 3: `GreedyIndependentSet` + CELF lazy greedy

**Files:** Create `crates/divsel/src/greedy.rs` · Test: inline

**Interfaces (produced):**

```rust
pub fn greedy_independent_set(
    pts: &Points, util: &mut dyn Utility, d: f32, k: usize,
) -> Vec<usize>;
```

Implements the paper's subroutine exactly: maintain `nearest: Vec<f32>` (distance from each unselected point to `S`, initialized `f32::INFINITY` per `dist(u,∅)=∞`); each round the candidate set is `{v : nearest[v] >= d}`; pick `argmax g(v|S)`, **ties → lowest index** `[divsel choice]`; commit; update `nearest` in one `O(n)` pass. Return early when `C` is empty.

CELF: a max-heap of `(gain, last_eval_round, idx)`; pop, re-evaluate if stale, push back if it fell below the new top. **Skip the heap entirely when `util.is_linear()`** — with constant marginals CELF is provably a no-op, and pretending otherwise is exactly the dead machinery `gist-select` ships.

- [ ] **Step 1: Failing tests** — (a) `d = 0` reproduces classic greedy on a hand-checked 6-point Linear instance; (b) `d` larger than the diameter returns exactly 1 point; (c) result is always a valid independent set: all pairwise distances `≥ d`; (d) CELF path and naive path return **identical** selections on 100 random FacilityLocation instances.
- [ ] Steps 2–4: implement → green → `cargo clippy -D warnings` → commit.

### Task 4: The GIST driver

**Files:** Create `crates/divsel/src/gist.rs`, `crates/divsel/src/lib.rs` (re-exports) · Test: inline

**Interfaces (produced — the public API):**

```rust
pub struct GistConfig { pub k: usize, pub lambda: f64, pub eps: f32, pub exhaustive_thresholds: bool }
impl Default for GistConfig { /* k: 10, lambda: 1.0, eps: 0.1, exhaustive_thresholds: false */ }

pub struct GistResult { pub selected: Vec<usize>, pub f_value: f64, pub div: f32, pub threshold: f32 }
```

`thresholds` implements `{ (1+eps)^i · eps·d_max/2 : (1+eps)^i ≤ 2/eps }` exactly. `exhaustive_thresholds = true` switches to `{dist(u,v)/2}` over all pairs — the paper's exact-`2/3` variant, `O(n²)`, intended for `n ≲ 2000`; the docs state that bound.

The driver runs line 1 (greedy at `d=0`), lines 2–5 (diameter + diametrical-pair check, **strict `>`**, requires `k ≥ 2`), then the sweep with **non-strict `≥`** at line 9. Tie-direction matters for reproducibility and is asserted in tests.
